# JZL OpenClaude

JZL OpenClaude será um orquestrador local para padronizar projetos desenvolvidos por IA, tornando sua estrutura, seu código e suas decisões técnicas mais previsíveis e facilitando a revisão e a manutenção humanas.

O fluxo central é simples: **JZL controla -> OpenClaude executa -> modelo raciocina**.

O projeto está em estágio inicial. Sua direção de produto e sua arquitetura conceitual estão documentadas em:

- [Visão do produto](docs/VISAO_DO_PRODUTO.md)
- [Arquitetura conceitual](docs/ARQUITETURA_CONCEITUAL.md)
